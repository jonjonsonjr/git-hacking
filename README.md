# git-hacking

Boss walking towards you? Friends mocking your hacking skills? Put them all to shame with the prowess of a thousand Unix beards with git-hacking.

Git-hacking is an application designed for the lazy at heart. Step into the shoes of the original author of any codebase. Point git-hacking at a git-repository and recreate any code and feel like a real hacker. Feel the wind through your beard as you breeze through code. Think hackertyper, but with a targeted codebase.
